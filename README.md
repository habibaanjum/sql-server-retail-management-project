# Retail Sales & Inventory Management System (SQL Server)

## Project Overview
This project demonstrates advanced SQL Server skills including:

- Database Design & Normalization
- Primary & Foreign Keys
- Indexing
- Stored Procedures with Transactions
- Triggers
- Views
- Performance Optimization
- Analytical Queries

## Tools Used
- Microsoft SQL Server
- SQL Server Management Studio (SSMS)

## Key Features
- Order creation with transactional integrity
- Automatic stock update
- Stock validation trigger
- Sales reporting view
- Performance indexing
- Top selling product analytics

## How to Run
1. Run 01_Create_Database.sql
2. Run remaining files in sequence.
3. Execute sample stored procedure.
